# AGENTS.md

## Project workflow

This project uses a lightweight engineering log. When making any relevant change, update the root-level `NOTES.md` file before finishing the task.

### Required behavior
- After code, config, data-prep, model, or training changes, add a brief summary to `NOTES.md`.
- Record:
  - what changed
  - which files were touched
  - why it changed
  - any verification output or test result
  - what's left to do
- Keep `NOTES.md` concise but current.
- If a change is substantial, add a short dated section or update the existing status section.

### Scope
This applies to any future coding session in this workspace, including:
- model training updates
- prediction logic changes
- dataset changes
- project structure updates
- dependency or environment work

### Goal
`NOTES.md` acts as the working memory for this project so progress survives across chats and restarts.
